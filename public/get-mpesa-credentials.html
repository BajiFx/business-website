M-Pesa Credentials Setup

Follow these steps to get your real M-Pesa API credentials

1

Create Safaricom Developer Account

Go to developer.safaricom.co.ke and create an account. You'll need to verify your email.

2

Create an App

In the developer portal, go to "My Apps" and click "Create New App".
Note: For testing, you can use the "Sandbox" environment.

3

Get Consumer Key & Secret

After creating your app, you'll see your Consumer Key and Consumer Secret. Copy both.

Example:
Consumer Key: your_consumer_key_here
Consumer Secret: your_consumer_secret_here
4

Get Passkey

Go to "Sandbox" → "Credentials". You'll find your Passkey. Copy it.

Passkey: your_passkey_here
5

Setup ngrok for Callback URL

M-Pesa needs a public URL to send payment confirmations. For development, use ngrok:

npm install -g ngrok
ngrok http 3000

Copy the forwarding URL (e.g., https://xxxx.ngrok.io) and use it as your callback URL.

🔑 Enter Your Credentials

These will be saved to your .env file

Default: 174379 (Sandbox)
Use your ngrok URL

📄 Generated .env Configuration

# M-Pesa Configuration MPESA_CONSUMER_KEY=your_consumer_key MPESA_CONSUMER_SECRET=your_consumer_secret MPESA_PASSKEY=your_passkey MPESA_SHORTCODE=174379 MPESA_CALLBACK_URL=https://your-ngrok-url.ngrok.io/api/payments/mpesa-callback MPESA_ENVIRONMENT=sandbox
